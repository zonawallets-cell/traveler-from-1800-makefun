One sentence explaining the modern internet to a traveler from 1800 —
built only from things they already know: a library, a post office, a
letter, ink. Every library and post office on earth, folded into a single
room, its door standing open in every house, its letters arriving before
the ink is dry.

## Run it

```sh
python3 main.py
```

Writes the sentence to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` overrides the
output directory). Deterministic: the same sentence, byte for byte, on every run.
